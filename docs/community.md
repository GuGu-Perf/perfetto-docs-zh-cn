# 社区与获取帮助

## 提问

提问的最佳场所是 **#help** 频道，位于我们的 [Discord 服务器](https://discord.gg/35ShE3A)
上。Perfetto 团队和社区会在那里答疑，通常在几小时内回复。提问时请附上你的
Perfetto 版本、进行 Tracing 的平台，以及（如果可以的话）trace 文件本身。

如果你偏好邮件，也可以在我们的
[公开邮件列表](https://groups.google.com/forum/#!forum/perfetto-dev) 上提问。

**Googlers**：也请使用 Discord，除非你的问题涉及仅限内部知晓的细节。
这类问题请使用 [YAQS](https://go/perfetto-yaqs) 或我们的
[内部邮件列表](http://go/perfetto-dev)。如果你的事务确实紧急，请参见
[此页面](http://go/perfetto-project)。

## 报告 bug

对于影响 Perfetto 任何部分（**Chrome tracing 除外**）的 bug，请使用
[GitHub issues](https://github.com/google/perfetto/issues)。

对于影响 Chrome tracing 的 bug，请使用 http://crbug.com 并标注
`Component:Speed>Tracing label:Perfetto`。

**Googlers**：请使用内部 bug 跟踪器
[go/perfetto-bugs](http://goto.google.com/perfetto-bugs)。

## 跟踪开发动态

- **版本发布**会在 [Discord](https://discord.gg/35ShE3A) 的 #announcements 频道、
  [GitHub releases](https://github.com/google/perfetto/releases) 和
  [邮件列表](https://groups.google.com/forum/#!forum/perfetto-dev) 上公布。
- **设计提案（RFC）**在
  [GitHub Discussions](https://github.com/google/perfetto/discussions/categories/team-design-discussions)
  中讨论。新的 RFC、issue 和讨论也会发布到 Discord 的 #github 频道。
- 如需贡献代码，参见[贡献指南](/docs/contributing/getting-started.md)。

## 行为准则

Perfetto 遵循
[Google 开源社区准则](https://opensource.google/conduct/)。
